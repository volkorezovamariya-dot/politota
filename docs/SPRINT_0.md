# Sprint 0 — Foundation

## Цель

Проверить, что Politota можно представить как объяснимую систему сигналов, а не как непрозрачный «рейтинг стран».

## Результат спринта

К концу Sprint 0 в репозитории должны быть:

- открываемый в браузере прототип;
- единая схема демонстрационного сигнала;
- фильтры по стране, категории и уверенности;
- объяснимый расчёт приоритета и агрегированного риска;
- документация по границам MVP;
- backlog следующего этапа.

## Definition of Done

- [x] Создана рабочая ветка `sprint-0/foundation`.
- [x] Описана цель продукта и принципы доверия к данным.
- [x] Создан статический дашборд без сборщика.
- [x] Добавлен демонстрационный набор сигналов.
- [x] Реализованы фильтры и расчёт сводных показателей.
- [x] Каждый сигнал содержит источник, дату, уверенность и влияние.
- [ ] Подключён автоматический smoke-check.
- [ ] Проведён ручной просмотр мобильной версии.
- [ ] PR переведён из draft после проверки.

## Формулы прототипа

Приоритет отдельного сигнала:

`priority = impact × 0.6 + confidence × 0.4`

Риск страны:

1. Для каждого сигнала рассчитывается `impact × confidence`.
2. Значения усредняются.
3. Результат масштабируется коэффициентом 1.25 и ограничивается диапазоном 0–100.

Формула временная. Её задача — обеспечить прозрачное поведение интерфейса до появления исторических данных и калибровки.

## Следующий спринт
