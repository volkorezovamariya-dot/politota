# Politota

**Politota** — аналитическая система раннего обнаружения политических и социально-экономических изменений.

Система собирает открытые сигналы, связывает их с событиями и помогает отвечать на три вопроса:

1. Что меняется прямо сейчас?
2. Почему это может быть важно?
3. Какое решение или событие вероятно следующим?

## Sprint 0

Текущая ветка: `sprint-0/foundation`.

Цель Sprint 0 — собрать проверяемый фундамент MVP:

- единая модель сигнала;
- базовый индекс риска страны;
- статический прототип дашборда;
- демонстрационные данные;
- архитектурные границы и backlog.

## Запуск локально

Проект не требует сборщика:

```bash
python3 -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

## Структура

```text
politota/
├── index.html              # интерфейс MVP
├── styles.css              # визуальная система
├── app.js                  # фильтры, расчёты и рендеринг
├── data/signals.json       # демонстрационные сигналы
└── docs/
    ├── SPRINT_0.md          # цели и критерии готовности
    └── ARCHITECTURE.md      # архитектурный контур
```

## Принципы

- источник и дата обязательны для каждого сигнала;
- факт отделяется от интерпретации;
- прогноз содержит вероятность и аргументы;
- отсутствие данных не маскируется нулём;
- индекс объясним: пользователь видит, из чего он сложен.

## Статус

🚧 Активная разработка. Данные в Sprint 0 демонстрационные и не должны использоваться как фактическая политическая оценка.
